**A high-end website concept for a painting and decorating company in East London. It has an interactive before-and-after slider, a portfolio, a process timeline, FAQs, and scroll-reveal animations.**

## Features

- An editorial-style hero and a "the work you don't see" craftsmanship section
- **Seven service disciplines**, each clearly presented
- An interactive **drag-to-compare before and after slider**
- A **selected work** portfolio and a **process timeline** from enquiry to
  completion
- Testimonials, an FAQ, and a project enquiry form
- **Scroll-reveal animations** with staggered delays
- **Cookie consent**, privacy policy, terms, and cookie policy pages
- SEO basics: a canonical URL, a sitemap, and robots.txt

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

```
index.html
cookie-policy.html, privacy-policy.html, terms-conditions.html
css/style.css, js/main.js, images/
sitemap.xml, robots.txt
```

## Run locally
